# Portfolio image slots

Add approved portfolio images here as you receive them. The first two supplied studio images should become the primary hero/portrait set.

Suggested naming:
- hero.jpg — strongest full-length image
- portrait.jpg — close-up/beauty portrait
- runway-01.jpg, runway-02.jpg — runway
- editorial-01.jpg, editorial-02.jpg — editorial
- fashion-01.jpg, fashion-02.jpg — fashion/designer work
- commercial-01.jpg — commercial/TVC
- campaign-01.jpg — campaign

The React portfolio currently uses intentional image placeholders so the layout does not need to be rebuilt when new photos are added.
